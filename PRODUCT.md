# PennyWise

PennyWise helps individuals track everyday money with manual entries, monthly category budgets, separate accounts, and upcoming bills. The first release uses Philippine pesos and stores records in the current browser without signup.

The Daily Companion overview puts the total balance, quick transaction entry, upcoming bills, and budget progress first. The web app supports phones and desktops and reopens offline after an initial online load.

Recording a bill payment creates an expense. It never transfers money to a provider. Backup imports combine records after a preview and explicit conflict choices. Browser records can be lost, so exporting backups is part of the core workflow.

Cloud sync, shared accounts, bank connections, debt planning, and savings goals are deferred.
